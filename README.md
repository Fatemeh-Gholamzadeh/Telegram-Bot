# Telegram Translation Bot (Python)

This project is a Telegram Translation Bot developed using Python.  
The bot translates messages between English and Persian using Google Translate API.

---

## Features

- /start command with inline buttons (Channel & Support)
- /help command with usage instructions
- Language selection using custom keyboard
- English → Persian translation
- Persian → English translation
- Automatic message handling
- Interactive chat flow using next step handler

---

## Technologies Used

- Python 3
- pyTelegramBotAPI (telebot)
- googletrans
- Telegram Bot API
- Git & GitHub
